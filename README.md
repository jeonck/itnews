# IT Daily Brief

An automated English-language IT news briefing, published every morning at
**06:00 US Central** to **https://itnews.metacog.co.kr/**.

Each edition covers four beats — **AI / ML**, **Development**,
**Big Tech & Startups**, **Security & Cloud** — with 2–4 items per beat, one or
two sentences on why each matters, and a source link.

## How it works

```
Claude routine (cloud, 06:00 CT daily)
  └─ web search over the last 24h across the four beats
     └─ writes content/posts/YYYY-MM-DD.md
        └─ commits & pushes to main
           └─ GitHub Actions → Hugo build → GitHub Pages → itnews.metacog.co.kr
```

The routine's full instructions live in [CLAUDE.md](CLAUDE.md) — post format,
filename rule, date/timezone rule, and sourcing rules. Edit that file to change
what gets published; the routine reads it on every run.

## Structure

```
.
├── CLAUDE.md                   # briefing spec the daily routine follows
├── hugo.toml                   # PaperMod config, baseURL = custom domain
├── content/posts/YYYY-MM-DD.md # one briefing per day
├── content/about/              # what this site is
├── static/CNAME                # itnews.metacog.co.kr
├── themes/PaperMod/            # git submodule
└── .github/workflows/deploy.yml
```

## Local development

```bash
git clone --recurse-submodules https://github.com/jeonck/itnews.git
cd itnews
hugo server -D        # http://localhost:1313
hugo --minify         # production build
```

If you cloned without `--recurse-submodules`:

```bash
git submodule update --init --depth=1
```

## Operations

- **Site config** — `hugo.toml`. Theme is [PaperMod](https://github.com/adityatelange/hugo-PaperMod) (submodule, so CI checks out with `submodules: true`).
- **Custom domain** — `static/CNAME` plus a `CNAME` DNS record for `itnews` → `jeonck.github.io`.
- **Schedule** — managed at <https://claude.ai/code/routines>. The cron is UTC, so the local fire time shifts by an hour between CDT and CST.
- **Manual deploy** — Actions tab → *Deploy to GitHub Pages* → Run workflow.
- **Backfill a day by hand** — copy an existing post, fix the filename and `date`, run `hugo --minify`, commit.

## Disclaimer

Summaries are generated by an AI system and can contain errors. Follow the
