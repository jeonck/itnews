*Everything that mattered in tech over the last 24 hours, in about two minutes.*

## 🤖 AI / ML

### Google launches Gemini 4 Argon, retaking the frontier benchmark lead
Argon sets new state-of-the-art scores on long-horizon software engineering, legal/finance work, and video understanding, and can generate up to 1 million output tokens in a single run — but Google is rolling it out cautiously, giving cyber defenders in its Fairwind Program first access before wider availability. — [Google](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-4-argon/)

### OpenAI and Synopsys team up to build GPT-Synopsys for chip design
The multi-year partnership will produce a specialized model trained to operate Synopsys' EDA tools directly — running them, reading their output, and iteratively optimizing power, performance, and area — under a revenue-sharing deal, with customer design data excluded from training. — [Synopsys](https://news.synopsys.com/2026-09-30-OpenAI-and-Synopsys-Announce-GPT-Synopsys-Frontier-Intelligence-to-Revolutionize-Chip-Design)

## 🛠 Development

### Ivo open-sources Sage, the first free legal AI model for contract work
Built by post-training DeepSeek V4 Flash with reinforcement learning on a legal-agent benchmark, Sage jumped from 70% to 91% pass rate on long-horizon contract tasks like redlines and drafting — and is now downloadable for attorneys and developers to fine-tune freely. — [GlobeNewswire](https://www.globenewswire.com/news-release/2026/10/01/3372932/0/en/ivo-becomes-the-first-legal-ai-company-to-publish-a-free-open-source-model-post-trained-for-long-horizon-contract-work.html)

### GitHub ships September updates to Copilot in VS Code
New releases let developers start a Copilot chat before attaching a workspace and pick up a Codex conversation from the ChatGPT app without re-pasting context, while several older models (including GPT-5.5 and GPT-5.4) are slated for deprecation on October 19. — [GitHub Changelog](https://github.blog/changelog/2026-10-01-github-copilot-in-vs-code-september-2026-releases/)

## 🏢 Big Tech & Startups

### PaleBlueDot AI raises $200M Series C at a $3.2B valuation
The Palo Alto "Super Intelligence Infrastructure" startup, which combines owned GPU clusters, a GPU marketplace, and serverless inference, says it has already signed over $5 billion in customer contracts and will use the round led by ComputeCore to add more compute capacity and hardware choice. — [Unite.AI](https://www.unite.ai/palebluedot-ai-raises-200m-series-c-at-3-2b-valuation-to-expand-super-intelligence-compute/)

### Nebius acquires Israeli startup Inferize for up to $150M
The 10-month-old, 17-person Tel Aviv company — founded by Granulate alumni — built technology that scales AI inference capacity to actual demand to cut idle GPU costs; it will be folded into Nebius's Token Factory inference platform. — [Globes](https://en.globes.co.il/en/article-nebius-acquires-10-month-old-israeli-startup-inferize-1001558149)

## 🔐 Security & Cloud

### GitLab patches critical 9.9-severity AI Gateway RCE flaw
CVE-2026-90970 let an authenticated user with Duo Agent Platform access escape the prompt-template sandbox via a crafted flow configuration and run arbitrary commands; GitLab's own hosted gateways are already patched, but self-hosted AI Gateway operators must update to 19.2.4, 19.3.2, or 19.4.1. — [The Hacker News](https://thehackernews.com/2026/10/gitlab-patches-critical-self-hosted-ai.html)

### Microsoft: AI has given attackers a speed advantage over defenders
The 2026 Digital Defense Report finds the median time from vulnerability discovery to weaponization has fallen below 24 hours, phishing-led intrusions jumped from 7% to 23% of incidents year-over-year, and researchers observed the first automated ransomware-extortion attack in the wild. — [Microsoft](https://www.microsoft.com/en-us/security/blog/2026/10/01/insights-from-the-2026-microsoft-digital-defense-report/)

### Azure gateway failure disrupted connectivity across 18 regions
A change to Azure's regional gateway management service collided with unrelated OS maintenance on September 30, overloading dependent services and degrading ExpressRoute, VPN Gateway, Azure Firewall, and VMware Solution connectivity worldwide for roughly six hours before Microsoft rolled back the change. — [The Register](https://www.theregister.com/off-prem/2026/10/01/azure-maintenance-mess-disrupted-hybrid-clouds-vpns-cloudy-vmware-services/5300333)
