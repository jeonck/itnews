## 🤖 AI / ML

### Anthropic says Claude designed working protein binders for 14 of 15 lab targets
In an independent lab test run by Adaptyv Bio and Twist Bioscience, Claude Opus 4.8 and an experimental "Mythos Preview" model autonomously ran the protein-design workflow — identifying binding regions, generating candidate structures, and ranking them — hitting a 22-35% success rate against the 10-15% industry norm, with some binders outperforming the best previously published results. — [Anthropic](https://www.anthropic.com/research/Claude-accelerates-protein-design), [Dataconomy](https://dataconomy.com/2026/08/20/claude-ai-protein-binders-14-of-15-targets/)

### OpenAI previews zero-retention "Private Safety Processing" to rival Anthropic on privacy
OpenAI is testing a system with early enterprise customers like Microsoft and Databricks that flags misuse patterns across multiple conversations without retaining any customer data or exposing prompts to human reviewers, sending only a narrow abuse signal. A full rollout and technical white paper are planned for September; it currently covers enterprise and API customers only, not consumer ChatGPT plans. — [TechCrunch](https://techcrunch.com/2026/08/19/openai-seeks-to-one-up-anthropic-with-new-customer-privacy-protections/), [Axios](https://www.axios.com/2026/08/19/openai-previews-zero-retention-safety-system-as-anthropic-requires-data-logs)

## 🛠 Development

### GitHub suffers multi-hour global outage, taking Copilot down with it
A traffic spike overwhelmed networking equipment at one of GitHub's US data centers, and an auto-scaling safeguard failed to kick in, cascading into a login-system failure that broke the website, PR review tools, Actions, and Copilot for over three hours. A separate VS Code bug then sent 10x normal traffic to Copilot's login service, keeping it down even after the rest of GitHub recovered. — [GeekWire](https://www.geekwire.com/2026/github-outage-disrupts-developers-worldwide-in-latest-setback-for-microsoft-coding-platform/)

### GitHub ships Agent Plugins 1.0, now generally available everywhere Copilot runs
The spec — built with AWS, Anysphere, Microsoft, OpenAI, and Vercel — lets developers bundle a skill with an MCP server into one portable plugin that works across VS Code, Copilot CLI, the Copilot SDK, and the Copilot app, discoverable through the Awesome Copilot marketplace. Existing plugins remain supported with no migration required. — [GitHub Changelog](https://github.blog/changelog/2026-08-12-agent-plugins-1-0-in-vs-code-copilot-cli-and-the-copilot-app/)

## 🏢 Big Tech & Startups

### Unitree's Shanghai IPO pops as much as 629% in record-oversubscribed debut
The humanoid-robot maker raised $904M on Shanghai's STAR Market, and shares surged as much as 629% intraday (closing up 460%) after an offering oversubscribed more than 8,000 times — a STAR Market record — pushing its market cap to roughly $66B. Backers include Tencent, Alibaba, Meituan, and DeepSeek. — [CNBC](https://www.cnbc.com/2026/08/19/china-backflipping-robot-maker-unitree-jumps-shanghai-ipo.html), [Forbes](https://www.forbes.com/sites/johnkoetsier/2026/08/19/unitree-ipos-massive-629-pop-makes-agility-robotics-look-super-cheap/)

### Samsung hikes advanced foundry prices up to 15% as AI chip demand outstrips supply
Reuters reports Samsung raised contract chipmaking prices on its 4nm and 5nm processes by up to 15% for orders placed in July, with Chinese customers absorbing the steepest increases as US export curbs push them toward overseas foundries. The move follows a similar TSMC hike and comes as Samsung's foundry market share has fallen to 7.3%, down from 11.5% a year ago. — [KFGO/Reuters](https://kfgo.com/2026/08/19/samsung-hikes-chipmaking-prices-by-up-to-15-on-demand-spike-sources-say/)

## 🔐 Security & Cloud

### Public exploit turns Citrix NetScaler flaw into unauthenticated root RCE
Researchers at watchtowr published a working proof-of-concept showing CVE-2026-8452, a pre-authentication heap overflow in NetScaler ADC and Gateway's packet-processing engine, can be escalated to full remote code execution as root — far worse than Citrix's original June bulletin, which described it only as a denial-of-service risk. There is no workaround; only upgrading to patched firmware (14.1-72.61 / 13.1-63.18 or later) protects against it. — [CSO Online](https://www.csoonline.com/article/4192741/new-citrixbleed-like-netscaler-flaw-sees-exploit-attempts-in-the-wild.html), [watchtowr Labs](https://labs.watchtowr.com/youre-back-in-the-room-citrix-netscaler-pre-auth-rce-cve-2026-8452/)

### CISA adds four actively exploited flaws to its KEV catalog
The newly added vulnerabilities span Microsoft SharePoint (CVE-2026-55040, weak authentication, CVSS 9.1), Broadcom VMware vCenter (CVE-2026-59310, path traversal enabling code execution, CVSS 9.8), Apple macOS (CVE-2026-65400, improper authentication), and Microsoft's IKE service (CVE-2026-33824, double-free). Federal agencies must remediate by August 21. — [The Hacker News](https://thehackernews.com/2026/08/critical-macos-sharepoint-vcenter-and.html), [CISA](https://www.cisa.gov/news-events/alerts/2026/08/18/cisa-adds-four-known-exploited-vulnerabilities-catalog)
