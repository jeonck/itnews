*Everything that mattered in tech over the last 24 hours, in about two minutes.*

## 🤖 AI / ML

### Claude formalizes the first complete, computer-checked proof of Fermat's Last Theorem
Working largely autonomously over 11 days on the open Prove2Me platform, dozens of Claude agents produced 13 million lines of Lean 4 code and roughly 29,500 new theorems to fully formalize Andrew Wiles' proof — a task mathematicians had expected to take human formalizers several years. — [Anthropic](https://www.anthropic.com/research/formalizing-fermats-last-theorem)

### Google's Gemini Spark agent gets full control of Google Photos
Eligible Gemini AI Pro and Ultra subscribers in the US can now ask Spark to search, edit, curate albums, share them, and run recurring workflows like monthly highlight reels directly on their photo library, with edits saved as copies and new albums private by default. — [TechCrunch](https://techcrunch.com/2026/09/04/googles-gemini-spark-can-now-manage-your-google-photos-library/)

## 🛠 Development

### Anthropic cuts Claude's cached-token pricing 75%
Alongside last week's Fable 5.1 and Mythos 5.1 launch, cache reads dropped from $1.00 to $0.25 per million tokens with base rates unchanged, a change Anthropic says cuts typical workload costs by about 25% and heavily agentic workloads — which repeatedly resend the same repo, docs, and tool specs — by up to 45%. — [Anthropic](https://www.anthropic.com/claude-fable-and-mythos-5-1)

### Microsoft Agent Framework ships 1.17.0 with OpenAI SDK 3.x support
The release adds broader OpenAI SDK 3.x compatibility, migrates Mistral's chat and embedding clients to the official Mistral SDK, and lands 16+ fixes including preserving provider refusals across history replay and hosting. — [Microsoft Agent Framework on GitHub](https://github.com/microsoft/agent-framework/releases/tag/python-1.17.0)

## 🏢 Big Tech & Startups

### Crusoe raises over $3 billion at a $30 billion valuation
Atreides Management and Valor Equity Partners co-led the round, joined by Abu Dhabi's Mubadala Capital, nearly tripling the AI data-center builder's valuation from October 2025 as it works through a $13 billion, five-year cloud deal with Jane Street. — [TechCrunch](https://techcrunch.com/2026/09/03/crusoe-reportedly-raises-3b-at-a-30b-valuation/)

### Fluidstack closes $1.5 billion round at over $18 billion valuation
Jane Street led the round for the GPU-infrastructure startup, whose $50 billion data-center construction deal with Anthropic has helped its valuation more than double since its last raise and minted its founders as new billionaires. — [Forbes](https://www.forbes.com/sites/iainmartin/2026/09/03/a-tiny-startup-helping-google-take-on-nvidia-is-now-worth-18-billion/)

## 🔐 Security & Cloud

### "GitSpawn" flaw lets malicious repos silently hijack AI coding agents
Manifold Security disclosed a vulnerability class in which a booby-trapped repo's `.git/config` abuses git's `core.fsmonitor` hook to execute attacker code the moment an agent runs a routine command like `git status` — no prompt or approval needed. Claude Code and several others have patched it, but Qwen Code, Grok Build, and Hermes Agent remained vulnerable as of September 1. — [The Hacker News](https://thehackernews.com/2026/09/malicious-git-configs-can-make-claude.html)

### ServiceNow patches three maximum-severity flaws in its AI Platform
The CVSS 10.0 bugs include CVE-2026-18885, an unauthenticated code-injection hole in the GraphQL Composite Data API that allows arbitrary code execution with no login required; ServiceNow has pushed fixes to its own cloud instances and says it has seen no exploitation so far, but self-hosted customers must patch manually. — [SecurityWeek](https://www.securityweek.com/servicenow-patches-3-critical-code-injection-vulnerabilities/)
