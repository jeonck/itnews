*Everything that mattered in tech over the last 24 hours, in about two minutes.*

## 🤖 AI / ML

### OpenAI ships GPT-6.1 Sol, always-on "Dots" agents, and a $500/mo Pro tier at DevDay 2026
At its San Francisco developer conference, OpenAI unveiled more than 20 updates including GPT-6.1 Sol (95% cheaper cached input), Dots — always-on agents with their own cloud computer and access to 4,000+ apps — a new Agents API with native computer use, and a $500/month Pro plan. — [OpenAI](https://openai.com/index/devday-2026-recap/)

### Anthropic warns China's GLM-5.3 lowers the bar for AI-built cyberattacks
Anthropic's Frontier Red Team found the open-weight model built full exploit chains in real-world tests — including turning a disclosed Chrome flaw into working code in under a day — while its safety guardrails were bypassed 64–100% of the time with simple jailbreaks. — [Anthropic](https://www.anthropic.com/research/glm-5-3-and-the-spread-of-advanced-cyber-capabilities)

### Trump and top AI firms sign voluntary "self-policing" accord
Executives from OpenAI, Anthropic, Google, Microsoft, and Meta joined President Trump at the White House to sign a roughly 300-word pact of internal and external audits for frontier AI; Trump called it "morally binding" but the commitments remain voluntary. — [CNBC](https://www.cnbc.com/2026/09/29/tech-white-house-ai-lunch-trump.html)

## 🛠 Development

### GitHub Copilot adds GPT-6.1 Sol for agentic coding
The model is now generally available in Copilot for Pro+, Max, Business, and Enterprise users, with GitHub reporting it completes multistep coding and terminal tasks using noticeably fewer tokens and steps than prior models. — [GitHub Changelog](https://github.blog/changelog/2026-09-29-gpt-6-1-sol-in-github-copilot/)

### GitHub Copilot CLI 1.0.89 can now read Claude Code rule files
The release lets Copilot CLI import `.claude/rules` custom instructions directly, alongside a routing-tier auto-suggestion feature and PR creation that follows a repo's pull request template. — [GitHub](https://github.com/github/copilot-cli/releases/tag/v1.0.89)

## 🏢 Big Tech & Startups

### Anthropic's leaked IPO prospectus targets a $2 trillion valuation
Reuters reported the prospectus points to an October Nasdaq listing at more than double Anthropic's $965B May mark, alongside a 12x revenue jump to $4.6B in 2025, a $42B net loss (including a $34B non-cash charge), and $518B in planned future cloud-infrastructure commitments. — [CNBC](https://www.cnbc.com/2026/09/28/anthropics-ipo-prospectus-shows-sweeping-ai-vision-surging-costs-reuters.html)

### OpenAI's revenue run rate nears $70 billion as enterprise sales double
OpenAI's annualized revenue run rate grew more than 70% since the start of Q3, with B2B revenue more than doubling, up sharply from the roughly $40B run rate reported just a month earlier — though its cost base remains opaque. — [Axios](https://www.axios.com/2026/09/29/scoop-openais-annual-recurring-revenue-nears-70b)

## 🔐 Security & Cloud

### Pentagon breach exposes SSNs of over 3 million service members
A vulnerability in a Defense Manpower Data Center file-sharing system, active from October 2025 until its July 2026 discovery, let unauthorized users access unencrypted personal data — including Social Security numbers — for 2.76 million living and 294,000 deceased individuals. — [Time](https://time.com/article/2026/09/29/pentagon-department-defense-manpower-data-center-breach-personnel-information/)

### Chrome patches critical ANGLE buffer overflow among 33 flaws
Version 154.0.8037.92/.93 fixes CVE-2026-102331, a CVSS 9.6 buffer overflow in Chrome's ANGLE graphics engine that could let a malicious webpage execute code outside the browser sandbox. — [SecurityOnline](https://securityonline.info/chrome-154-security-update/)
