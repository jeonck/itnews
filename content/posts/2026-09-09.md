*Everything that mattered in tech over the last 24 hours, in about two minutes.*

## 🤖 AI / ML

### OpenAI claims a 10,000-agent swarm cracked the Navier-Stokes Millennium Prize Problem — but won't claim the $1M
An unreleased internal model spawned roughly 10,000 concurrent agents that reportedly found a proof of finite-time blowup in 88 hours, with GPT-6 Astra spending another 17 hours formalizing it in the Lean theorem prover; mathematicians dispute the claim because the result covers the "forced" equations, not the unforced version the Clay Mathematics Institute's prize actually requires. — [OpenAI](https://openai.com/index/navier-stokes-solution/)

### DeepMind's AlphaGenome Atlas precomputes the effect of every possible human DNA mutation
The free, 1-petabyte database — more than 30x the size of the AlphaFold Database — scores all 9 billion possible single-letter genome changes with a new "AVI" impact metric designed to separate disease-causing mutations from harmless ones, removing the need for researchers to run the model themselves. — [Google DeepMind](https://deepmind.google/blog/alphagenome-atlas-a-predictive-map-of-every-possible-dna-letter-change-in-the-human-genome/)

## 🛠 Development

### npm ships three GA updates to lock down trusted publishing
Packages can now register multiple OIDC trusted-publisher configurations at once, staged package approvals now require malware scanning to finish first, and maintainers get a detailed history view of staged publishes — all aimed at closing gaps in npm's supply-chain security model. — [GitHub Changelog](https://github.blog/changelog/2026-09-03-multiple-trusted-publishing-configurations-for-npm/)

### Herdr 0.9 merges local and remote machines into one terminal client
The open-source terminal workspace manager for AI coding agents now lets developers manage SSH-connected remote machines alongside their local one in a single window, with a combined agent list and automatic reconnects, instead of juggling separate terminal tabs per host. — [Herdr on GitHub](https://github.com/herdrdev/herdr/releases/tag/v0.9.0)

## 🏢 Big Tech & Startups

### Qualcomm and AWS ink multi-generation deal worth up to $60B in custom AI chips
The partnership will co-develop custom AI inference silicon and 1.6Tbps optical interconnects for AWS data centers through 2036; Qualcomm issued Amazon a warrant for 25 million shares that vests as AWS actually buys hardware, and Qualcomm's stock jumped 10% on the news. — [The Register](https://www.theregister.com/off-prem/2026/09/08/amazon-ropes-qualcomm-into-something-something-ai-networking-chips/5295071)

### Mistral raises Europe's largest-ever tech funding round: €3B at a €21B valuation
Samsung Electronics led the Series D, nearly doubling Mistral's valuation from a year ago; CEO Arthur Mensch says the money will go toward building and owning data centers rather than just renting cloud capacity, as European "sovereign AI" investment accelerates. — [TechCrunch](https://techcrunch.com/2026/09/08/mistral-raises-e3b-as-sovereign-ai-becomes-big-business/)

## 🔐 Security & Cloud

### Microsoft's September Patch Tuesday fixes a record 966 flaws, including two exploited zero-days
CVE-2026-85880 (Windows ALPC elevation of privilege) and CVE-2026-81963 (a Windows Update Stack link-following flaw) were both actively exploited before patching; the release also includes 105 Critical-rated bugs, 81 of them remote code execution. — [BleepingComputer](https://www.bleepingcomputer.com/news/microsoft/microsoft-september-2026-patch-tuesday-fixes-966-flaws-2-zero-days/)

### Adobe patches "StyleSmuggler," a Magento zero-day that backdoored fully-patched stores
CVE-2026-75650 (CVSS 10.0) let unauthenticated attackers trigger PHP code execution by abusing Magento's payment-failure email template; Sansec found it being used in the wild since September 4 to plant a Rust backdoor and PHP web shells, and Adobe's fix ships as a composer hotfix for Commerce 2.4.4+ and Magento Open Source 2.4.6+. — [The Hacker News](https://thehackernews.com/2026/09/adobe-patches-magento-zero-day.html)

### Huntress finds a new N-central exploit chain used to breach a fully-patched server
Investigating a September 4 compromise, Huntress uncovered an undocumented chain of CVE-2026-86206 and CVE-2026-86207 that bypasses authentication to create rogue administrator accounts — a fifth distinct attack path against N-able's N-central platform in six weeks, deepening one of the year's longest-running RMM security incidents. — [Huntress](https://www.huntress.com/blog/n-able-vulnerability-exploitation)
