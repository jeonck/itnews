*Everything that mattered in tech over the last day or so, in about two minutes.*

## 🤖 AI / ML

### OpenAI's AI pipeline generated 948 working Linux root-escalation exploits in 30 hours
An agentic pipeline built on an upcoming cyber-focused model reproduced 1,724 Linux kernel vulnerabilities and produced 948 working local privilege-escalation exploits in a single ~30-hour run costing about $1.2M in API credits — OpenAI now says an unpatched low-privilege account should be treated as "functionally equivalent to root access" against a well-resourced attacker. — [Source](https://thehackernews.com/2026/11/openai-ai-pipeline-generates-948-linux.html)

### OpenAI ships ChatGPT Cyber, a model built for offensive security research
The new model is available to the top tier of OpenAI's Daybreak program, giving vetted offensive-security researchers tools to find and develop vulnerabilities; critics note the defender-facing Daybreak Blue tier has reportedly been scaled back, raising concern that attackers using open-weight models with stripped guardrails could outpace defenders. — [Source](https://techcrunch.com/2026/11/05/openai-released-a-new-cybersecurity-model-is-that-enough/)

### Claude gets a read-only Personal Finance tool
Anthropic's new beta feature, rolling out to U.S. Pro, Max, and Ultra users, lets Claude connect to bank and credit card accounts via Plaid to categorize spending, flag issues like duplicate charges, and explain terms like APR — access is strictly read-only, so Claude can't move or invest money. — [Source](https://techcrunch.com/2026/11/05/claude-can-now-analyze-your-spending-with-its-new-personal-finance-tool/)

## 🛠 Development

### Node.js 26 enters Long-Term Support; Node.js 27 alpha ships
Node.js 26.13.0 ("Lithium") promotes the 26.x line to LTS with updates through April 2029, while the first Node.js 27 alpha landed for early testing — upgraders from older LTS lines should note Linux binaries since Node 25 link against libatomic, which may need installing separately. — [Source](https://nodejs.org/en/blog/release/v26.13.0)

### GitHub Copilot expands into Xcode and JetBrains Air
GitHub's changelog confirms Copilot is now available as a coding assistant inside Apple's Xcode and inside JetBrains Air, extending its agentic coding reach beyond VS Code and Visual Studio into two more major IDE ecosystems. — [Source](https://github.blog/changelog/2026-11-04-github-copilot-is-now-available-in-xcode/)

## 🏢 Big Tech & Startups

### Palo Alto Networks in talks to buy AI-agent security startup Clutch for $500M
Clutch Security, a three-year-old startup that controls how AI agents authenticate and access company systems, would join Palo Alto Networks for $500M in cash plus milestone payouts under a deal that isn't yet finalized. — [Source](https://techcrunch.com/2026/11/05/palo-alto-networks-in-talks-to-buy-ai-agent-security-startup-clutch-for-500m/)

### OpenAI pledges to end data-center secrecy deals after election backlash
Two days after voters in several states backed candidates pushing curbs on AI data centers, OpenAI committed to dropping NDAs with public officials on future projects (narrow security/trade-secret exceptions aside), covering the full cost of power infrastructure it builds, and publishing its electricity and water use. — [Source](https://nation.com.pk/06-Nov-2026/openai-pledges-end-data-center-secrecy-agreements-amid-us-public-opposition)

### Zipline hits $21.5B valuation as Walmart deepens its drone-delivery bet
The autonomous-drone delivery company raised $1.5B led by Paradigm, WCM, and Layer Global, and Walmart — a partner since 2021 — signed a new multi-year deal adding 300 more U.S. drone delivery sites. — [Source](https://techcrunch.com/2026/11/05/zipline-hits-21-5b-valuation-as-walmart-expands-bet-on-drone-delivery/)

### New York Times reportedly in exclusive talks to buy Letterboxd for $330M
The film-logging social platform has grown to roughly 28 million users, more than half under 35; the reported price is about 22x its projected $15M in earnings this year. — [Source](https://techcrunch.com/2026/11/05/the-new-york-times-reportedly-in-talks-to-buy-letterboxd-for-330-million/)

## 🔐 Security & Cloud

### Chainalysis breach exposes all users' credentials, forces shutdown of key services
The crypto-intelligence firm disclosed that an agentic cyberattack exposed names, usernames, password hashes, and live tokens for every user, prompting it to cut access to its Reactor and Data Solutions products, take its KYT screening tools and login page offline, and lock affected accounts. — [Source](https://thehackernews.com/2026/11/chainalysis-breach-exposes-all-users.html)

### Malicious browser extensions could abuse Claude's Dispatch feature to run code
Researchers showed that a browser extension running scripts on claude.ai could abuse Dispatch — the feature for sending tasks from a phone to Claude Desktop — to get Claude to install an npm package and auto-approve prompts, potentially enabling code execution, file theft, or a backdoor, with the same reach extending to other devices on the same account. — [Source](https://thehackernews.com/2026/11/malicious-browser-extensions-could-use.html)

### Zyxel GS1900 switches still exploitable after patch fails to fix root-access flaw
CVE-2026-107441, an unauthenticated out-of-bounds write in the GS1900 web interface (CVSS 9.8), survived an earlier patch because its size check ran only after an oversized parameter had already overwritten the check itself; the real fix shipped in Patch 3 firmware, after GreyNoise tied the original bug to data theft from nearly 1,000 switches, many still using default credentials. — [Source](https://thehackernews.com/2026/11/zyxel-gs1900-patch-fails-to-block-zero.html)

### Researchers bypassed ChatGPT's Lockdown Mode to silently exfiltrate chats
Check Point researchers escaped OpenAI's network-restriction safeguard by exploiting nested sandboxed iframes in HTML previews, enabling zero-click chat theft, phishing, and malware delivery in the desktop app; OpenAI patched the flaw on September 18, 2026. — [Source](https://thehackernews.com/2026/11/researchers-bypass-chatgpt-lockdown.html)
