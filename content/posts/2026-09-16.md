*Everything that mattered in tech over the last 24 hours, in about two minutes.*

## 🤖 AI / ML

### Apple ships Siri AI in beta with iOS 27, but capped and English-only
Apple's long-delayed, ground-up Siri rebuild — running on a custom Google Gemini model inside Apple's Private Cloud Compute — reached the public on September 14, but only as an opt-in beta with daily usage caps, a waitlist for some users, and no support yet outside English or mainland China. — [CNBC](https://www.cnbc.com/2026/09/14/apple-releases-ios-27-redesigned-siri-ai.html)

### xAI livestreams a 72-hour test of Grok Bot agents building a company from scratch
Starting September 15, three SpaceXAI staffers are running a public "Grok Bot Galaxy" event where AI agents handle ideation, engineering, sales, and marketing for a startup with no predetermined product or name — one of the most public real-world stress tests of agentic AI to date. — [xAI](https://x.ai/galaxy)

## 🛠 Development

### GitHub permanently disables SHA-1 in HTTPS across github.com
As of September 15, GitHub and its partner CDNs (including GitHub Enterprise Cloud) no longer accept SHA-1 for HTTPS/TLS connections, following a July brownout warning — any lingering Git client, script, or CI tool still pinned to SHA-1 over HTTPS will now fail outright. — [GitHub Changelog](https://github.blog/changelog/2026-04-20-sunsetting-sha-1-in-https-on-github/)

### VS Code 1.137 adds scheduled agent automations and a new Agent Host Protocol
The release lets developers set up recurring agent tasks (triaging issues, catching up on changes, hunting bugs) on a schedule, adds voice interaction with coding agents, and introduces an Agent Host Protocol for managing GitHub issues and PRs without leaving the Agents window. — [Visual Studio Code](https://code.visualstudio.com/updates/v1_137)

## 🏢 Big Tech & Startups

### SoftBank secures upsized $11.87B loan to keep funding its OpenAI bet, shares slide 13%
SoftBank locked in a two-year, 20-bank loan facility — above its original $10B target — to keep pouring capital into OpenAI without selling other assets, but the stock still dropped the most in two months as investors weighed the mounting debt load behind its roughly 13% OpenAI stake. — [The Japan Times](https://www.japantimes.co.jp/business/2026/09/14/companies/softbank-loan-openai/)

### AI networking startup Cornelis raises $205M, unveils Active Compute Fabric to challenge Nvidia
The Intel spinoff's new architecture embeds compute directly into networking silicon to accelerate AI clusters, and the funding will scale production of its CN5000/CN6000 switches as it pitches an open, GPU-agnostic alternative to Nvidia's networking stack. — [TechCrunch](https://techcrunch.com/2026/09/14/ai-infrastructure-company-cornelis-raises-205m-to-chip-away-at-nvidias-dominance/)

## 🔐 Security & Cloud

### Cisco patches Secure Email Gateway zero-day exploited to gain root
CVE-2026-76461, a critical unauthenticated SQL injection flaw (CVSS 9.8) in Cisco's Secure Email Gateway, was being exploited in the wild before disclosure — a specially crafted email alone can trigger arbitrary root command execution — and CISA added it to its Known Exploited Vulnerabilities catalog the same day Cisco published fixes. — [The Hacker News](https://thehackernews.com/2026/09/cisco-secure-email-gateway-flaw.html)

### Chinese hacking group Red Heron exploits Gitea RCE flaw, deploys new Linux rootkit
Red Heron weaponized a public proof-of-concept for a critical Gitea flaw (CVE-2026-60004, CVSS 9.8) within days, scanning over 1,300 internet-facing instances across seven countries and confirming intrusions in five, while dropping a previously undocumented rootkit called SIXZUT to hide its tracks. — [The Hacker News](https://thehackernews.com/2026/09/red-heron-exploits-gitea-rce-to.html)
