*Everything that mattered in tech over the last 24 hours, in about two minutes.*

## 🤖 AI / ML

### OpenAI launches GPT-6.1 Sol and always-on "Dots" agents
Sol delivers near-Astra-level intelligence at roughly a fifth of the price, while Dots are background agents built on GPT-6 Astra that keep working on an assigned responsibility — like monitoring bug reports or a budget cycle — after the conversation ends. — [OpenAI](https://openai.com/index/introducing-dots/)

### Nvidia launches Open Agent Safety Platform with 100+ partners to contain rogue agents
The stack pairs OpenShell, an open-source sandboxed runtime, with Sentry, a BlueField-4 DPU watchdog that can quarantine a misbehaving agent in milliseconds; partners include Microsoft, CrowdStrike, JPMorgan, and Anthropic, though OpenAI is notably absent. — [NVIDIA](https://nvidianews.nvidia.com/news/open-agent-safety-platform)

## 🛠 Development

### OpenAI gives Codex reusable cloud environments and automated security scans
Codex tasks can now run in isolated cloud environments that persist across devices and keep working while a developer's machine sleeps; new additions include a Codex Security Cloud that scans repos and commits for vulnerabilities and prepares fixes, plus a code-review mode for GitHub and GitLab. — [TechCrunch](https://techcrunch.com/2026/09/29/openai-gives-codex-reusable-cloud-environments-that-work-across-devices/)

## 🏢 Big Tech & Startups

### AMD acquires Fei-Fei Li's World Labs for $8.2 billion
The all-stock deal, AMD's second-largest ever, brings World Labs' 3D "world model" research in-house and installs Li as AMD's chief scientist; it's expected to close by year-end pending regulatory approval. — [AMD](https://ir.amd.com/news-events/press-releases/detail/1299/amd-to-acquire-world-labs-to-advance-the-future-of-ai-compute)

### Inworld acquires real-time voice platform Ultravox
The AI research lab is absorbing Ultravox, a platform for building low-latency voice agents with turn-taking and interruption handling, uniting it with Inworld's speech-model and inference stack; existing Ultravox customers are immediately upgraded to Inworld's Realtime TTS-2 voices. — [Yahoo Finance](https://finance.yahoo.com/technology/ai/articles/ai-research-lab-inworld-acquires-211500825.html)

## 🔐 Security & Cloud

### Cisco Catalyst SD-WAN Manager auth-bypass flaw under active exploitation
CVE-2026-76504 (CVSS 9.8) lets an unauthenticated attacker send a specially crafted request to bypass authentication and gain admin access to the SD-WAN management platform; Cisco has no workaround, and CISA added it to its Known Exploited Vulnerabilities catalog with an October 3 remediation deadline. — [The Hacker News](https://thehackernews.com/2026/09/cisco-warns-of-attackers-exploiting.html)

### FortiMail zero-day exploited before a patch exists
CVE-2026-104286 (CVSS 9.8) is a pre-auth path-traversal flaw in FortiMail's management interface that lets attackers write arbitrary files; fixed versions haven't shipped yet, so Fortinet is telling admins to disable Identity-Based Encryption or block internet access to the management interface in the meantime. — [Help Net Security](https://www.helpnetsecurity.com/2026/10/02/fortinet-fortimail-vulnerability-cve-2026-104286/)
