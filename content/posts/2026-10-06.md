*Everything that mattered in tech over the last 24 hours, in about two minutes.*

## 🤖 AI / ML

### Trump creates a "Super Intelligence Force" to steer federal AI policy
President Trump signed an executive order directing agencies to replace "artificial intelligence" with "Super Intelligence" in official use and named former SEC chair Jay Clayton to lead a new White House task force, alongside FTC chair Andrew Ferguson and Pentagon CTO Emil Michael, to coordinate AI dominance efforts and oversight. — [NBC News](https://www.nbcnews.com/politics/trump-administration/trump-announces-members-ai-task-force-rcna601494)

### Report: Meta and Microsoft are pulling back on internal Claude use
Microsoft's Claude Code usage reportedly dropped to around 30,000 employees from roughly 60,000 as it leans on its own tooling, while Meta's internal MetaCode and Muse Spark models have displaced much of its Claude usage — a sign of Big Tech's push to reduce reliance on Anthropic as it builds competing coding agents. — [Yahoo Finance](https://finance.yahoo.com/technology/ai/articles/meta-microsoft-scale-back-internal-185842649.html)

## 🛠 Development

### GitLab previews Orbit, an agent-native backend built with Anthropic
Unveiled at GitLab Transcend, Orbit lets coding agents query the repository server-side for only the data a task needs instead of cloning it, with early tests showing agents running up to 11x faster, using 4.5x fewer tokens, and producing far fewer hallucinations; it's also exposed as a standalone context API for third-party tools via MCP. — [GitLab](https://about.gitlab.com/blog/gitlab-transcend-announcements/)

### Anthropic ships "mods" for customizing Claude Code
Mods are small TypeScript functions that can rewrite prompts, add UI, or replace built-in Claude Code behavior entirely, giving developers a lightweight extension model instead of forking the tool — a notable shift toward making coding agents end-user programmable. — [Anthropic](https://claude.com/blog/claude-code-mods)

## 🏢 Big Tech & Startups

### Anthropic reportedly pushes ahead on an IPO targeting a $2 trillion valuation
Anthropic is said to be moving toward a public listing as soon as November, with revenue up roughly 12x year-over-year to near $4.6 billion in 2025 despite heavy losses — a valuation that would more than double its May private-market mark and test investor appetite for AI-industry bets. — [CNN](https://www.cnn.com/2026/10/05/business/anthropic-ipo-stock-market)

### NetSPI and Synack's merger set to close this month, forming a $200M+ offensive security platform
The KKR-backed combination pairs NetSPI's penetration-testing-as-a-service business with Synack's AI-assisted Red Team platform, aiming to build the industry's largest bench of offensive security researchers paired with agentic pentesting tools as the market shifts from point-in-time tests to continuous testing. — [NetSPI](https://www.netspi.com/newsroom/press-release/netspi-and-synack-to-merge-forming-a-leading-offensive-cybersecurity-platform/)

## 🔐 Security & Cloud

### Critical Atlassian flaw exposes files across eight Data Center products
CVE-2026-21589 (CVSS 9.3) lets unauthenticated attackers read arbitrary files within the web root of Jira, Confluence, Bitbucket, Bamboo, Crowd, Crucible, and Fisheye Data Center deployments if they already know the target filename; Atlassian Cloud is unaffected and patches are available for all impacted self-hosted versions. — [The Hacker News](https://thehackernews.com/2026/10/critical-atlassian-flaw-lets.html)

### Suspected AI-assisted hacking spree hits seven South Korean financial firms
Shinhan Bank, KB Kookmin, Hana Bank, Busan Bank, Hyundai Capital, and two savings banks reported breaches exposing roughly 67,000 customers' names, contact details, and resident registration numbers; investigators are examining whether attackers used the open-source ARTEX AI penetration-testing framework, prompting regulators to order emergency security reviews across the sector. — [Korea Times](https://www.koreatimes.co.kr/business/banking-finance/20261005/ai-powered-attacks-on-banks-expose-technological-lag-in-koreas-financial-cyber-defenses)
