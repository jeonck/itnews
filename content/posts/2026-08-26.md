*Everything that mattered in tech over the last 24 hours, in about two minutes.*

## 🤖 AI / ML

### Claude's memory now spans chat and Cowork
Anthropic unified Claude's memory across chat and its Cowork agent, saving context as conversations happen rather than summarizing afterward, while excluding sensitive topics like health, religion, and political beliefs by default unless a user opts in. — [Claude Blog](https://claude.com/blog/claudes-memory-works-everywhere-and-you-decide-whats-in-it)

### OpenAI retires o3 from ChatGPT
The reasoning model left ChatGPT's model picker after a 90-day sunset period announced in May, with existing o3 conversations now continuing on GPT-5; the o3 API remains unaffected for now. — [Forkast](https://forkast.news/openai-retired-o3-from-chatgpt-today-the-real-cost-is-the-churn-it-forces-on-everyone-else/)

## 🛠 Development

### Kubernetes v1.37 ships
The release graduates SELinux relabeling with mount options, KYAML, and pod certificates to stable, while phasing out legacy cgroup v1 support and moving rootless kubelet and cgroup v2 memory QoS to beta — a significant maintenance-relevant release for cluster operators. — [Kubernetes Blog](https://kubernetes.io/blog/2026/07/31/kubernetes-v1-37-sneak-peek/)

## 🏢 Big Tech & Startups

### Taiwan charges Nvidia, Super Micro staff in AI chip smuggling case
Prosecutors charged nine people, including employees of Nvidia and Super Micro, with falsifying documents to reroute roughly 50 Super Micro servers loaded with restricted Nvidia chips to China via Taiwan and Japan, evading U.S. export controls. — [Washington Post](https://www.washingtonpost.com/business/2026/08/24/taiwan-china-us-nvidia-ai-server-chip-illegal-export/de0bb83c-9ff2-11f1-8606-1d40ad00172e_story.html)

### Bain joins Anthropic's Claude Partner Network at top tier
Bain & Company became a "Global Premier" partner alongside its existing 19,000-person internal Claude rollout, positioning the consultancy to sell Anthropic-powered AI transformation work to enterprise clients. — [Bain & Company](https://www.bain.com/about/media-center/press-releases/2026/bain-company-announces-partnership-with-anthropic-to-accelerate-clients-enterprise-ai-transformations/)

## 🔐 Security & Cloud

### Nvidia NemoClaw flaw let a single webpage hijack local AI agents
CVE-2026-65105, disclosed by Oasis Security, stemmed from NemoClaw binding Ollama to 0.0.0.0:11434 without authentication; a DNS-rebinding attack from a malicious page could rewrite an agent's chat template and plant persistent hidden instructions. Fixed in v0.0.35 for macOS and Linux, but Windows/WSL remains unpatched. — [The Hacker News](https://thehackernews.com/2026/08/a-malicious-webpage-could-poison-your.html)

### Marimo notebook flaw ran MCP commands before code execution
A code-injection bug (CVE-2026-75149, CVSS 8.8) let an attacker embed a malicious MCP server entry in a shared notebook that executed as a local subprocess the moment the notebook opened in edit mode, before any cell ran. Fixed in Marimo 0.23.15. — [The Hacker News](https://thehackernews.com/2026/08/marimo-notebook-flaw-could-run-mcp.html)
