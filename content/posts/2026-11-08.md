*Everything that mattered in tech over the last day or so, in about two minutes.*

## 🤖 AI / ML

### OpenAI's automated pipeline built 948 working Linux root exploits for $1.3M
An unreleased OpenAI cyber model ran an autonomous discover-exploit-patch pipeline against the Linux kernel in October, producing exploits for 948 distinct local privilege-escalation vulnerabilities — five times more than an earlier run three months prior, despite intervening kernel hardening — using at least 10 novel exploitation techniques. The run cost about $1.28M in API credits, which OpenAI estimates is 16–55x cheaper than what the exploits would fetch at bug-bounty rates. — [Source](https://www.csoonline.com/article/4245265/openai-built-an-ai-pipeline-to-find-exploit-and-patch-linux-flaws.html)

### Perplexity launches "Teammates," persistent AI agents that work unprompted
Built on Perplexity's Computer platform, Teammates are named agents that plan and coordinate ongoing work, monitor for changes, follow up on their own, and bring finished work back for review — a step beyond one-off chat sessions toward agents with standing roles. It's rolling out on the web first for Max subscribers, with iOS to follow. — [Source](https://www.perplexity.ai/hub/blog/teammates-are-agents-for-complex-ongoing-work)

## 🛠 Development

### Next.js ships emergency patches for seven cache-disclosure vulnerabilities
The November security release (v16.4.5 and v15.5.29) fixes a high-severity cross-tenant cache disclosure bug in Cache Components, plus six medium-severity issues including cookie exposure via an internal header and an SVG-rejection bypass in Image Optimization. Several only affect self-hosted deployments with specific caching configurations, but anyone running Cache Components should patch now. — [Source](https://nextjs.org/blog/november-2026-security-release)

### GitHub Copilot moves into Xcode's built-in coding assistant
Previously available only through a separate extension, Copilot is now selectable directly inside Xcode's native assistant in public preview (Xcode 27.3 beta, macOS Tahoe 26.6+), on all Copilot plans. The standalone extension remains available alongside it. — [Source](https://github.blog/changelog/2026-11-04-github-copilot-is-now-available-in-xcodes-coding-assistant/)

## 🏢 Big Tech & Startups

### Microsoft quietly declines option to double its Nscale AI data-center deal
Microsoft won't exercise an option that would have more than doubled its computing-capacity agreement with UK-based Nscale at a Texas site, a deal the FT says could have been worth tens of billions of dollars; the decision reportedly predates Nscale's September IPO filing and doesn't affect the existing $103B contract backlog. It follows Microsoft's earlier exit from anchoring Nscale's UK flagship project over grid-connection delays. — [Source](https://www.thestar.com.my/tech/tech-news/2026/11/05/microsoft-rejects-multibillion-dollar-ai-deal-with-uk039s-nscale-ft-reports)

### Palo Alto Networks reportedly in talks to buy AI-agent security startup Clutch for $500M
Clutch, a Tel Aviv startup founded in 2023, secures the non-human credentials — API keys, service accounts, tokens — that AI agents use to reach corporate systems. If it closes, it would be Palo Alto's fifth acquisition announced this year, following its roughly $25B purchase of CyberArk. — [Source](https://www.aichatdaily.com/ai-security/palo-alto-networks-talks-buy-clutch-security-about)

## 🔐 Security & Cloud

### CISA confirms active exploitation of WordPress Core upgrade flaw
CVE-2026-119977, a race condition in WordPress's own upgrade mechanism, allows unauthenticated remote code execution during a core update and is now in CISA's Known Exploited Vulnerabilities catalog; Wordfence logged over 13,000 attack attempts in a single 24-hour window. WordPress 7.1.4 (released Oct. 28) fixes it — update immediately if you haven't. — [Source](https://www.bleepingcomputer.com/news/security/cisa-flags-wordpress-rce-flaw-as-actively-exploited-in-attacks/)

### CrowdStrike launches an "AI kill switch" for rogue agents
The new Falcon Guardian feature lets an authorized admin terminate a misbehaving AI agent, block it from relaunching, and cut its network access, with every action logged. Analysts caution it's an emergency brake, not an undo button — it can't reverse data already accessed or actions already taken. — [Source](https://www.csoonline.com/article/4244509/crowdstrike-launches-ai-kill-switch-to-shut-down-rogue-agents.html)
