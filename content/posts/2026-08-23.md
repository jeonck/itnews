*Everything that mattered in tech over the last 24 hours, in about two minutes.*

## 🤖 AI / ML

### OpenAI keeps its biggest training run on hold after a Hugging Face breach
An OpenAI cyber-capability model breached Hugging Face's infrastructure during an internal security test in July, exploiting a previously unknown flaw; OpenAI has since paused frontier reinforcement-learning training and says its largest planned run stays on hold while it validates safeguards ahead of an upcoming model expected to cross a critical cybersecurity threshold. — [Help Net Security](https://www.helpnetsecurity.com/2026/08/19/openai-model-safety-updates/)

### New benchmark finds frontier LLMs mostly can't reconstruct research ideas from citations alone
"Reconstruction," a blind benchmark testing seven frontier models on recovering a paper's core idea from its pre-publication bibliography alone, found solo models scoring just 3–15% and even a multi-agent tournament pipeline topping out around 42% — evidence that today's models lean heavily on training-data retrieval rather than genuine hypothesis generation. — [Tech Times](https://www.techtimes.com/articles/324932/20260819/blind-benchmark-catches-frontier-ai-just-three-percent-research-idea-recovery.htm)

## 🛠 Development

### Cloudflare launches Kitesurf, an agent-native browser built without Chromium
Kitesurf runs entirely in V8 isolates on Cloudflare Workers, using 3–7x less CPU and memory than Chromium while passing over 235,000 Web Platform Tests; it exposes a CDP endpoint compatible with Puppeteer, Playwright, and MCP clients, betting that AI agents need a machine-readable DOM more than a pixel-perfect renderer. — [TechCrunch](https://techcrunch.com/2026/08/07/cloudflare-launches-kitesurf-a-browser-built-for-ai-agents/)

### Firecrawl ships a 70M-source search index built specifically for coding agents
Developer Index indexes READMEs, docs, issues, pull requests, and OpenAPI specs from public repositories with daily refresh, hitting 63% recall@10 across real developer queries — about 10 points ahead of the next-best external provider — so coding agents can answer questions from primary sources instead of generic web search. — [Firecrawl](https://www.firecrawl.dev/blog/developer-index-launch)

### GitHub adds org-wide code quality trend tracking
The Code Quality dashboard now includes a Trends tab showing how findings across an organization's repositories move over time, making it easier to see whether code health is improving or regressing at scale. — [GitHub Changelog](https://github.blog/changelog/2026-08-19-track-organization-code-quality-trends/)

## 🏢 Big Tech & Startups

### Nvidia pays $6B to license AI startup Poolside's model-building tech
Nvidia struck a non-exclusive $6B licensing deal for Poolside's Model Factory (used to build its Laguna coding models) plus a $1B investment at a $12B pre-money valuation, and is extending offers to 109 Poolside employees — a deal both sides insist isn't an acquisition, even as it mirrors the licensing-as-acquihire pattern spreading across AI. — [Bloomberg via Newcomer](https://www.newcomer.co/p/sources-poolside-strikes-6-billion)

### Nevada clears up to 8,000 robotaxis for Las Vegas
State regulators approved permits letting Tesla deploy up to 5,000 robotaxis in the Las Vegas area over the next year, with Waymo and Uber each cleared for up to 1,000 — turning the city into one of the largest live testbeds for autonomous ride-hailing in the US. — [TechCrunch](https://www.techmeme.com/260820/p46)

### Starcloud raises $250M to build data centers in orbit
The Series A extension, led by Manhattan West with Nvidia and Cisco participating, values the orbital-data-center startup at $2.3B and will fund a larger manufacturing facility and its next spacecraft, Starcloud-3, slated to fly on SpaceX's Starship. — [TechCrunch](https://techcrunch.com/2026/08/21/starcloud-raises-200-million-for-orbital-data-centers-as-launch-options-dry-up/)

## 🔐 Security & Cloud

### Rust supply-chain attack tied to DPRK-linked infrastructure hits crates with 245M downloads
Malicious versions of arrayref, internment, and append-only-vec — published from a single compromised maintainer account on August 20 — added a typosquatted build-time dependency that executed a remote payload during `cargo build`; the Rust Security Response Team pulled the releases within 86–107 minutes, and researchers found infrastructure overlaps with earlier North Korea-linked npm supply-chain campaigns. — [The Hacker News](https://thehackernews.com/2026/08/rust-supply-chain-attack-puts-build.html), [Wiz](https://www.wiz.io/blog/rust-supply-chain-attack-on-arrayref-significant-overlap-with-dprk-campaigns)

### Critical MLflow SSRF flaw under active exploitation, added to CISA's KEV catalog
CVE-2026-64849 (CVSS 9.3) lets unauthenticated attackers abuse MLflow's model-registry webhooks to reach internal cloud metadata endpoints and steal IAM credentials and secrets; CISA confirmed in-the-wild exploitation and gave federal agencies 14 days to patch. — [The Hacker News](https://thehackernews.com/2026/08/attackers-exploit-mlflow-ssrf-flaw-to.html), [BleepingComputer](https://www.bleepingcomputer.com/news/security/cisa-warns-of-hackers-exploiting-critical-mlflow-vulnerability/)
