*Everything that mattered in tech over the last day or so, in about two minutes.*

## 🤖 AI / ML

### OpenAI launches GPT-6 Cyber after it finds 81 unknown Firefox flaws
OpenAI's new cybersecurity-focused model is rated "Critical" risk under its Preparedness Framework and scored 48.5% on the ExploitGym benchmark versus 32.1% for its predecessor; OpenAI says the model helped uncover 81 previously unknown high-severity Firefox vulnerabilities and is initially limited to vetted Daybreak Red customers. — [Source](https://thehackernews.com/2026/11/openai-launches-gpt-6-cyber-after-ai.html)

### Meta introduces Spaces, turning Muse agents into persistent project workspaces
Spaces let users spin up topic-focused, self-updating workspaces inside Meta's Muse AI agent — for trip planning, gift tracking, or DIY projects — that can connect to third-party apps and refresh themselves in the background, pushing Muse from one-off chats toward ongoing agentic work. — [Source](https://techcrunch.com/2026/11/06/meta-introduces-spaces-a-new-way-to-collaborate-with-your-muse-agent/)

## 🛠 Development

### GitHub rebuilds its Git storage backend for the agentic-coding era
GitHub detailed "Project Rubicon," a new storage architecture that stores packs in Azure Blob Storage with a replicated reference log and disposable virtual replicas, built to handle the write volume of thousands of concurrent coding agents — internal tests saw 5,000 agents sustain 7,200 pushes per second against one repo. It's in limited private preview now, with a broader rollout planned for early next year. — [Source](https://github.blog/engineering/architecture-optimization/inside-githubs-new-git-storage-architecture/)

### libghostty hits 1.0, giving developers a reusable terminal-emulation core
The C library extracted from Ghostty is now API/ABI-stable, MIT-licensed, and runs on everything from Linux to WebAssembly; JetBrains already uses it for its IDE terminals (12.5M+ active users), and Neovim and Turborepo are adopting or experimenting with it. — [Source](https://mitchellh.com/writing/libghostty-1-0)

## 🏢 Big Tech & Startups

### OpenAI reportedly raises $11B of a possible $20B round at a $1.25T valuation
The partial raise falls well short of the $30B at a $1.4T valuation OpenAI was said to be seeking in September, and comes as Bloomberg reports buyers may value Anthropic's upcoming IPO as low as $1.1T — down from roughly $2T expected a month earlier — amid broader market jitters over data-center politics after the midterms. — [Source](https://techcrunch.com/2026/11/06/openai-reportedly-raises-an-additional-11-billion-at-a-1-25-trillion-valuation/)

### Ramp data shows enterprise AI spending stalling just as Anthropic nears its IPO
Payments platform Ramp's transaction data suggests corporate AI spending growth is leveling off, raising questions about enterprise demand right as Anthropic prepares to go public. — [Source](https://techcrunch.com/2026/11/06/ramp-data-shows-ai-spending-stalling-just-as-anthropic-nears-its-ipo/)

### Google takes over Crusoe's stalled Wyoming data center project
Google bought an unfinished 10-gigawatt-planned data center campus in southeastern Wyoming from Crusoe after the independent developer struggled with cost and schedule, and will invest $17B to build it out itself — a sign hyperscalers are willing to step in directly when third-party AI infrastructure projects fall behind. — [Source](https://techcrunch.com/2026/11/06/crusoe-sells-troubled-wyoming-data-center-project-to-google/)

## 🔐 Security & Cloud

### Claude Code's "don't ask again" setting leaked secrets into 1,122 public GitHub repos
Apiiro found over 104,000 copies of Claude Code's local settings file across GitHub, including 1,122 public repos holding 1,379 live-looking secrets — passwords and API keys get saved in plain text when a user approves "don't ask again," and deleting the file afterward doesn't remove it from git history or forks. — [Source](https://thehackernews.com/2026/11/claude-codes-dont-ask-again-file.html)

### Hundreds of Artex AI hacking-agent deployments found exposed with no password
Censys found more than 800 internet-facing, unauthenticated deployments of Artex, an open-source autonomous pentesting tool already linked to attacks on South Korean banks and a Microsoft-cloud-hosted spying campaign against thousands of organizations — one exposed instance appeared to be holding stolen data from other victims. — [Source](https://techcrunch.com/2026/11/06/hundreds-of-artex-ai-hacking-tools-found-publicly-exposed-to-the-web/)

### Attackers exploited new OpenSSH "SSHole" flaw within nine hours of disclosure
CVE-2026-123158 (CVSS 8.1) lets an unauthenticated attacker log into passwordless accounts on musl-based Linux systems like Alpine by sending an oversized password; researchers saw the first real-world exploitation attempt against a honeypot less than nine hours after the CVE was published, with attackers gaining root. OpenSSH 10.6p2 fixes it. — [Source](https://thehackernews.com/2026/11/hackers-exploited-openssh-sshole-flaw.html)

### Chained Barracuda flaws let attackers reach root on Email Security Gateway with no login
CVE-2026-116606 (9.3 CVSS, auth bypass) and CVE-2026-111560 (8.6 CVSS, root command injection) can be combined for unauthenticated root access; Barracuda has shipped patches for all affected products and recommends restricting admin interfaces to trusted networks in the meantime. — [Source](https://thehackernews.com/2026/11/experts-demonstrate-barracuda-email.html)
