*Everything that mattered in tech over the last 24 hours, in about two minutes.*

## 🤖 AI / ML

### Nvidia launches a 64GB DGX Spark at $4,999 as memory prices spike
The new GB10 configuration halves the RAM and storage of the original DGX Spark to give local-AI developers a cheaper entry point, while the existing 128GB model has climbed to roughly $6,950 — up nearly 75% — as HBM demand for AI data centers squeezes supply of general-purpose memory like LPDDR5X. — [Tom's Hardware](https://www.tomshardware.com/pc-components/gpus/nvidia-introduces-64gb-dgx-spark-to-throw-local-ai-fans-a-lifeline-amid-the-rampocalypse-new-gb10-config-starts-at-usd4999-for-those-who-can-work-with-less)

### Perplexity open-sources a 27B "decision" model and opens a Decisions API
pplx-decider-v1-27b is a multimodal generative discriminator fine-tuned from Qwen3.8-27B that outputs a probability distribution over a fixed set of answers instead of free text, aimed at classification, routing, and rubric-grading tasks; it's released on Hugging Face under Apache 2.0 and priced at $0.04 per million input tokens with free output. — [Perplexity Docs](https://docs.perplexity.ai/docs/decisions/quickstart)

## 🛠 Development

### Windows 11 version 26H2 is now generally available
The annual feature update is a light one on new capabilities — default-on cloud backups of settings, just-in-time "administrator protection" against privilege-escalation attacks, and File Explorer navigation tweaks — but it resets the support clock, giving Home and Pro editions 24 more months of updates. — [Microsoft Tech Community](https://techcommunity.microsoft.com/blog/windows-itpro-blog/an-it-pro%E2%80%99s-guide-to-windows-11-version-26h2/4559760)

### GitHub CLI 2.102.0 patches four security flaws
The release fixes a symlink bug that let `gh release download` and similar commands write remote content outside the intended destination, a case-insensitive branch check that could fool attestation verification, an option-injection flaw in interactive skill search, and a workflow-prefix matching bug in attestation checks — GitHub is urging all `gh` users to update. — [GitHub](https://github.com/cli/cli/releases/tag/v2.102.0)

## 🏢 Big Tech & Startups

### Tesla stock jumps 5% after Q3 deliveries beat estimates
Tesla delivered 486,532 vehicles in the July–September quarter, topping analyst expectations of roughly 463,761 even though deliveries fell 2% year-over-year from last year's EV-tax-credit-driven rush — a sign demand is stabilizing faster than Wall Street expected. — [CNBC](https://www.cnbc.com/2026/10/02/tesla-tsla-q3-2026-vehicle-delivery-production.html)

### Crypto scammers hijack Microsoft's official X account for a fake "Clippy" token
For about 30 minutes attackers controlled the verified account's 13 million followers, swapped the profile picture to Clippy, and pushed a viral campaign to promote an unauthorized cryptocurrency token before Microsoft regained control; the company says it has not sanctioned any token tied to Clippy, Microsoft, or its stock ticker. — [SecurityWeek](https://www.securityweek.com/crypto-scammers-hijack-microsofts-official-x-account/)

## 🔐 Security & Cloud

### AWS previews a Well-Architected Agent that audits cloud setups and writes the fixes
The AI agent correlates utilization metrics, resource configs, and application topology against Well-Architected best practices across 65+ AWS services, then hands back dollar-impact findings with remediation as console walkthroughs, Infrastructure-as-Code diffs, or ready-to-run CLI commands — positioned as the successor to Trusted Advisor. — [AWS](https://aws.amazon.com/blogs/aws/announcing-aws-well-architected-agent-an-ai-powered-intelligence-to-optimize-your-cloud-environment-preview/)

### Apple tightens macOS Full Disk Access controls over AI-agent risk
Apple says it's adding stricter controls before an app can obtain Full Disk Access, warning that "as AI agents become increasingly capable and autonomous, the risks associated with this level of access will grow substantially"; the move follows a disputed claim that Meta's Muse app read a journalist's private messages on Mac. — [TechCrunch](https://techcrunch.com/2026/10/02/apple-says-its-tightening-macos-full-disk-access-controls-due-to-new-risks-from-ai-agents/)
